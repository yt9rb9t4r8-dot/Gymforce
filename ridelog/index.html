Подключение

Помощник работает через Claude API от Anthropic. Нужен твой API-ключ: создай его на platform.claude.com → API Keys и вставь сюда. Ключ хранится только на этом телефоне и не попадает в резервную копию. Запросы платные — оплата идёт с твоего аккаунта Anthropic. Твои записи и скриншоты, о которых ты спрашиваешь, отправляются в Anthropic для ответа.

AI меняет записи только по твоей просьбе. Удаление — всегда с подтверждением.
