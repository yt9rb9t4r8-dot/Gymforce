# RIDELOG — Private PWA (v0.2.0)

Рабочая версия личного приложения для учёта смен, доходов, расходов, календаря и обслуживания мотоцикла.

## Что уже работает
- Dashboard с доходом, расходами, заказами, километрами и часами.
- Начало/завершение смены и GPS tracking через Geolocation API.
- Сохранение смен, ручной ввод заказов, дохода и бонусов.
- Учёт доходов и расходов по категориям.
- Календарь с дневными итогами.
- Учёт одометра и интервалов обслуживания.
- Аналитика по сохранённым данным и простой локальный помощник.
- Экспорт и импорт резервной копии JSON.
- PWA manifest и service worker для установки и офлайн-оболочки.

## Важно: приватность и хранение
Эта первая версия хранит все данные в `localStorage` браузера на конкретном устройстве. Никакого аккаунта, облачной синхронизации или серверного хранилища пока нет. Это означает:
- данные не видны другим людям через приложение;
- очистка данных Safari/браузера может удалить записи;
- при переустановке/смене браузера данные не переносятся автоматически;
- регулярно скачивай резервную копию в разделе «Настройки».

Для настоящего закрытого доступа с авторизацией и синхронизацией нужно добавить backend (например, Supabase/Firebase), закрытые правила доступа и серверную проверку пользователя. Не публикуй секретные ключи в GitHub.

## Ограничения GPS на iPhone
Геолокация работает на HTTPS и требует разрешения пользователя. PWA на iOS не гарантирует непрерывное GPS-отслеживание при заблокированном экране или выгруженном Safari. В первой версии держи приложение открытым во время смены. Для надёжной фоновой записи нужна нативная iOS/Flutter-оболочка с background location capability.

GPS-километры этой версии — оценка по последовательности GPS-точек; неточности сигнала, городская застройка и паузы могут влиять на результат. Одометр мотоцикла пока вводится вручную.

## AI Analyst
В этой версии это локальная аналитика и ответы на ограниченный набор вопросов. Настоящая языковая модель пока не подключена. Для неё потребуется backend API, чтобы секретный API-ключ не попадал в браузер и GitHub.

## Запуск локально
Нужен локальный HTTP-сервер (не открывай `index.html` как `file://`, если хочешь тестировать service worker и PWA).

Например, Python (из папки `ridelog/`):
```bash
cd ridelog
python3 -m http.server 8000
```
Затем открой `http://localhost:8000`.

## Публикация через GitHub Pages
1. Создай новый приватный репозиторий GitHub с именем `ridelog`.
2. Загрузи содержимое этой папки в корень репозитория (или оставь в папке `ridelog/` — тогда адрес будет `…/ridelog/`).
3. В Settings → Pages выбери публикацию из ветки `main`, папка `/ (root)`.
4. Дождись выдачи HTTPS-ссылки.
5. Открой её в Safari на iPhone → Поделиться → На экран Домой.

**Примечание:** GitHub Pages не предоставляет контроль доступа к сайту только потому, что репозиторий private. Веб-сайт GitHub Pages может быть публичным в зависимости от плана и настроек организации. Эта PWA пока не имеет логина. Не размещай её как публичный сайт, если хочешь скрыть сам интерфейс. Для действительно приватного сайта потребуется hosting с access control и backend authentication.

- `app.js` — логика и локальное хранение.
- `manifest.webmanifest` — настройки установки PWA.
- `sw.js` — кэширование оболочки.
- `icon.svg` — иконка.
- `icons/` — PNG-иконки (iOS, Android, maskable).
