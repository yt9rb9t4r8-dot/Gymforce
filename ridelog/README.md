# RIDELOG v2.2.0 — Private PWA

Полностью обновлённая локальная PWA для личного учёта курьерской работы, финансов и Zontes 368G.

## Что включено
- Главная панель: чистый доход, расходы, заказы, км, время и прогноз месяца.
- HUD/смена: старт/финиш, GPS-трекинг при открытом приложении, платформа, заказы, доход, миссии, вычеты, район и заметка.
- Статистика: неделя/месяц/год/всё время, доход на заказ и км, сравнение Coupang/Baemin/других платформ, динамика и районы.
- Финансы: доходы/расходы и постоянные платежи.
- Zontes 368G: одометр, интервалы расходников, история ремонта и стоимость владения.
- Fuel Intelligence: заправки, л/100 км, цена литра.
- Цели: месячная цель, накопления и дневной челлендж.
- Календарь, реестр чеков, локальный AI-отчёт, экспорт/импорт JSON.
- PWA manifest + service worker; обновлённый cache key `ridelog-v2.0`.

## Новое в v2.2
- **Сегодня и вчера** на главной: чистыми, доход смен, заказы, доход в час — разница в ₩ и %.
- **История выплат** (Финансы): реальные переводы от платформ по неделям и месяцам; если указан период, сверка с заработанным по сменам. К доходу второй раз не прибавляется.
- **Долги** (Финансы): «я должен» / «мне должны», сумма, срок, частичная оплата, закрытие; просроченные — на главной.
- **Аренда аккаунта:** «Ещё → Настройки» — процент для каждой платформы. В форме смены сумма аренды считается сама (можно исправить), входит в расходы, чистую прибыль и сравнение платформ.
- **RIDELOG AI** (вкладка AI): принимает скриншоты и фото, распознаёт Coupang/Baemin и др., сам создаёт, меняет и удаляет записи через инструменты базы (смены, доходы/расходы, одометр, обслуживание, заправки, цели, чеки, выплаты, долги), строит отчёты. Удаление — только с подтверждением в приложении; дубли смен блокируются.
  - Работает через Claude API (Anthropic). Нужен свой API-ключ с platform.claude.com — он хранится только на телефоне (localStorage) и не попадает в резервную копию. Запросы платные. Модель по умолчанию — Claude Opus 5.5, можно выбрать Sonnet 5.5 или Haiku 5.5. Включён серверный резервный ответ при отказе модели (fallbacks).
  - SDK: официальный `@anthropic-ai/sdk` 1.3.0, собран в `vendor/anthropic-sdk-1.3.0.js`.

## Новое в v2.1
- **Экран смены:** большой таймер, START/FINISH, «Перерыв» (таймер и км на паузе), «Сброс», счётчик заказов −/+ (переносится в итоги смены), SOS (119 / 112 и мои координаты).
- **Парковка:** кнопки этажа L / 1F / B1–B4, «📍 Место» (GPS + этаж), «📷 Фото» места, список мест со ссылками на Kakao/Google карты. Хранятся последние 30 мест и 10 фото.
- **Запись смены:** платформа кнопками, район с автоподсказкой, вычеты; история смен с удалением.
- **Статистика:** день / неделя / месяц / год / всё время с листанием ‹ ›, неделя с понедельника или воскресенья, таблица по дням (платформа, заказы, оплата, миссии, время, км) с итогом, эффективность (₩/заказ, км/заказ, ₩/км), графики дохода в час и заказов, средний доход за рабочий день.
- **Сравнение платформ:** «на руки» с учётом вычетов и ставок налога/взносов из настроек, ₩/час на руки, лучшая платформа.
- **Расходники:** стандартный список по группам (двигатель и привод, тормоза и ходовая, электрика и впуск) с интервалом в км и/или месяцах, статус по одометру, «✓ Заменил» с записью в историю и расходы, редактирование интервалов; предупреждение на главной, когда пора менять.
- **Настройки:** ставки налога и взносов, погода на экране смены (по желанию).
- Графики без сглаживания, таблица помещается на экран телефона.

## Обновления — без выхода из приложения
Достаточно загрузить новые файлы в эту папку репозитория. Дальше всё само:
- приложение проверяет обновления при каждом открытии, при возврате в него и каждые 5 минут;
- если смены нет и ты ничего не печатаешь — новая версия ставится сразу (страница перезагружается и остаётся на том же разделе);
- если идёт смена или открыта клавиатура — сверху появляется кнопка «Новая версия — нажми, чтобы обновить»;
- данные и активная смена (таймер, GPS-км) переживают обновление;
- вручную: «Ещё» → «Обновления» → «Проверить обновления».

Service worker работает «сначала сеть», поэтому удалять ярлык с экрана Домой не нужно.

## Перенос данных
При первом запуске v2 данные прошлой версии (`ridelog_private_v1`) переносятся автоматически: финансы, смены, интервалы, история ремонта, одометр. Старая копия не удаляется. Импорт старого JSON-бэкапа тоже поддерживается.

## Исправления относительно присланного v2.0
- «Сегодня» считается по местному времени, а не по UTC (в Корее до 9:00 записи уходили во вчера).
- Активная смена сохраняется и не теряется при перезагрузке; экран не гаснет во время смены; фильтр скачков GPS по скорости.
- «Удалить все данные» действительно очищает данные; подтверждение перед удалением записи.
- Км сохранённой смены прибавляются к одометру.
- PNG-иконка для iPhone, поля ввода не приближают экран, экспорт работает в Safari.

## Важно
- Данные v2.0 хранятся в `localStorage` конкретного браузера/устройства. Это не облачный аккаунт и не синхронизация.
- Для настоящей приватной публикации нужны авторизация и backend с проверкой доступа. Private GitHub repository сам по себе не делает опубликованный сайт приватным.
- GPS на iPhone PWA не гарантирует запись при блокировке экрана или выгрузке приложения. Для фонового GPS нужна нативная iOS/Flutter-оболочка.
- Расходники и интервалы обслуживания — редактируемые напоминания, не официальная рекомендация Zontes. Сверяйся с руководством и сервисом.
- AI Analyst — локальный расчёт по твоим данным, не подключённая облачная модель.
- OCR чеков, автоматический импорт Coupang/Baemin и онлайн-карта тепловых зон не подключены; сейчас есть ручной ввод районов и чеков, статистика по ним.

## Запуск
Для локального теста: `python3 -m http.server 8000`, затем открой `http://localhost:8000`.
Для установки PWA нужен HTTPS-хостинг.
